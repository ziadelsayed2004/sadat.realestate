# Editing About page statistics

Open `/admin/content/about?lang=ar` (Content → About) and click **تعديل أرقام من نحن** / **Edit About statistics**. Edit the four display values and their Arabic/English labels. Uncheck a card to hide it; hiding every card hides the entire statistics section. Enter a change reason and save. The owning About block must be **published** and **active** for visitors to see these changes.

The button selects `about_intro` when present, otherwise the first statistics-bearing block, otherwise the first About block. Existing sites without saved statistics retain the previous four values until edited. No migration or changes to existing record identifiers are required. Values are display text (e.g. `1,200+` or `342K+`), not automatically calculated metrics. Editing uses the existing content permissions, version conflict checks and audit trail; unpublished content stays private.
