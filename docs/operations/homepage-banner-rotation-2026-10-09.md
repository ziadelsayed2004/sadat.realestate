# تشغيل بانرات الصفحة الرئيسية بالتبادل

يمكن نشر أكثر من بانر في موضع `homepage.hero` خلال نفس الفترة. تقرأ الصفحة البانرات السارية بالترتيب وتبدّل الصورة والعنوان والمحتوى والرابط معًا. حُذف تعارض الفترات لهذا الموضع من نشر البانرات وجدولة طلبات الإعلان المرتبطة بها. تظل قيود التعارض للمواضع الأخرى واشتراطات النشر والدفع أو الإعفاء الإداري كما هي.

## الإعداد من لوحة الإدارة

1. افتح **البانرات** وتأكد أن عرض بانرات الصفحة الرئيسية مفعّل.
2. اضغط **تعديل** لكل بانر. اجعل تاريخ البداية والنهاية يسمحان بعرض البانرات المطلوبة معًا في فترة متداخلة.
3. حدد **مدة عرض كل صورة (بالثواني)**، من 3 إلى 60 ثانية. مثال: البانر الأول 8 ثوانٍ والثاني 5 ثوانٍ. للبانر ذي عدة صور، تعرض كل صورة هذه المدة.
4. احفظ، ثم اضغط **نشر / جدولة** لكل مسودة. المسودة لا تدخل دورة العرض، والبانر المنتهي يخرج منها.
5. استخدم سهمي الترتيب لتحديد الأول والثاني. بعد آخر صورة ترجع الدورة إلى الأولى.

أُضيف هذا الشرح بجوار قائمة البانرات. التبديل يتوقف مؤقتًا أثناء التفاعل مع البانر ونموذج البحث، وعند إيقاف التشغيل من الواجهة. تُحترم تفضيلات تقليل الحركة وإخفاء تبويب المتصفح.

## التحقق

نجح 17 اختبار API و6 اختبارات متصفح بالعربية والإنجليزية على الكمبيوتر والتابلت والموبايل. شمل اختبار المتصفح نشر مسودتين في نفس الفترة، ثم عرض الأولى 3 ثوانٍ والثانية 5 ثوانٍ والعودة للأولى وتوقف التبديل عند الإيقاف المؤقت. نجح اختبار MongoDB فعلي في قاعدة محلية معزولة لنشر بانرين متداخلين بترتيبهما ومدتهما، وجدولة طلبين مدفوعين للموضع نفسه، واستمرار رفض التعارض في موضع آخر. نجح بناء الواجهة وفحص أنواع الواجهة وAPI وlint.

التعديل يحتاج تحديث السيرفر:

```bash
cd /root/sadat-release
git pull --ff-only origin main
bash deploy/native/manage-production.sh update
```
