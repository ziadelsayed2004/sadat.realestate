# تفعيل استثناء العمولة ووصوله إلى حساب مقدم العقار

## استخدام الاستثناء

1. افتح **العمولات ← إنشاء استثناء** واختر حساب مقدم العقار الصحيح.
2. اختر نوع العمولة وأدخل القيمة والسبب. «يبدأ الآن» يحدد بداية السريان، و«مستمر حتى أغيّره» يلغي تاريخ النهاية.
3. اضغط **حفظ مسودة**. هذه الخطوة تحفظ البيانات فقط؛ لا تغيّر النسبة ولا ترسل إشعار تفعيل.
4. اضغط **اعتماد وتفعيل الاستثناء** من نفس الصفحة، أو اعتمد المسودة من قائمة الاستثناءات. تحتاج صلاحية إدارة العمولات.
5. يدخل صاحب الحساب إلى `/provider/commission?lang=ar`. يظهر المصدر **استثناء معتمد** والقيمة الجديدة عندما تكون فترة الاستثناء سارية. يمكنه الضغط على **تحديث العمولة**، كما تتحدث البيانات عند الرجوع إلى الصفحة.
6. يصل إشعار داخل المنصة إلى `/provider/notifications?lang=ar` عند التفعيل أو الإيقاف. هذا ليس إرسال بريد إلكتروني أو واتساب، ولا يصل إلى حساب آخر.

**تأكيد الاطلاع على سياسة العمولة** مجرد إقرار بالاطلاع؛ لا يفعّل استثناء ولا يغيّر النسبة. الرسالة الخضراء في صفحة مقدم العقار كانت تخص هذا الإقرار.

## سبب ظهور النسبة الأساسية رغم الاعتماد

كان سجل الاستثناء يحفظ معرّف الحساب كنص، بينما قراءة صفحة مقدم العقار تبحث عنه كـ Mongo ObjectId فقط. أصبحت القراءة تدعم الصيغتين وتطبق أولوية الاستثناء الساري، ثم تخصيص الحساب، ثم السياسة الأساسية. لا تستطيع سياسة أساسية أحدث استبدال استثناء شخصي ساري.

التفعيل والإشعار وسجل التدقيق تُحفظ في معاملة واحدة. فشل المعاملة لا يترك إشعارًا لتفعيل لم ينجح. إصدار السجل يحدد هوية الإشعار لمنع تكراره عند إعادة المحاولة.

بعد نشر الإصلاح، تظهر الاستثناءات المعتمدة سابقًا إذا كانت سارية ومربوطة بالحساب الصحيح. الإصلاح لا يعيد إرسال إشعارات تاريخية تلقائيًا؛ الإشعارات الجديدة تصدر عند التفعيل أو تعديل الاستثناء النشط أو إيقافه. الاستثناء بتاريخ بداية مستقبلي لا يغيّر القيمة الحالية قبل هذا التاريخ.

## التحقق والنشر

تم اختبار الحفظ كمسودة، والتفعيل وإعادة محاولة التفعيل بدون إنشاء مسودة ثانية، وتحديث قراءة مقدم العقار، وفصل تأكيد مصدر العمولة القديم عن المصدر الجديد، وحالة رفض الصلاحية. اختُبرت قاعدة MongoDB محلية معزولة: المسودة تبقي 2.5%، والاعتماد يطبق 6% رغم سياسة أساسية أحدث، والإشعار يصل فقط إلى مقدم العقار المقصود، وفشل التدقيق يتراجع عن العملية، والإيقاف يعيد 2.5%.

نجح 44 اختبار مكونات، و17 اختبار API وسجل الاختبارات، و6 اختبارات متصفح بالعربية والإنجليزية على الكمبيوتر والتابلت والموبايل. نجحت مراجعة الأنواع والبناء للواجهة وAPI وlint، وفُحصت صور صفحة العمولة بالعربية على الكمبيوتر والموبايل.

يجب تحديث السيرفر ليظهر التعديل في الموقع العام:

```bash
cd /root/sadat-release
git pull --ff-only origin main
bash deploy/native/manage-production.sh update
```

بعد التحديث، أعد تحميل الصفحة وتحقق من الحساب المحدد في الاستثناء ومن حالته **فعالة** وفترة سريانه. لا تعتمد على رسالة تأكيد الاطلاع لإثبات تفعيل الاستثناء.
