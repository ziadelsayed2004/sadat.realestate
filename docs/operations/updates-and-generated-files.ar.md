# التحديثات وملفات الاختبارات

أمر التحديث نفسه مناسب لتعديلات الاستايل واللوجيك بعد رفعها على GitHub:

```bash
cd /root/sadat-release &&
git pull --ff-only origin main &&
sudo bash deploy/native/recover-disk-space.sh &&
sudo bash deploy/native/manage-production.sh update
```

وضع `update` ينشر الكود ويبني الواجهة والـAPI ويشغّل الفحوص، ثم يتحقق من صحة الخدمات. لا يعيد تثبيت الديمو ولا ينظف بيانات المستخدمين. توجد إعادة تشغيل قصيرة للخدمات أثناء تفعيل الإصدار؛ هذا ليس نشرًا بلا انقطاع.

يحتفظ الديبلوي بالإصدار الحالي وإصدار رجوع واحد فقط، وينظف مصادر البناء المؤقتة تحت `/opt/elsadatrealestate/staging`. سكربت `clean-release-artifacts.sh` يزيل تقارير الاختبارات والكاش وصور المراجعات من الإصدار الجديد بعد نجاح الفحوص، وينظف نفس البقايا من الإصدار الحالي ونسخة الرجوع أثناء الصيانة. لا يزيل ملفات `dist` أو صور الموقع أو `node_modules` المطلوبة للتشغيل أو قاعدة البيانات أو الرفع الخاص أو النسخ الاحتياطية. يتجاهل الروابط الرمزية ويرفض المسارات خارج إصدارات الديبلوي.

لتنظيف بقايا النشر دون نشر إصدار جديد:

```bash
cd /root/sadat-release &&
sudo bash deploy/native/recover-disk-space.sh
```

## ترتيب ملفات الريبو

- `apps/web/public/assets/`: صور وشعارات الموقع الفعلية، تظل في Git.
- `docs/design_sources/final_screens/` و`brand/`: مراجع التصميم المعتمدة التي تتأكد منها الاختبارات، تظل في Git وتُحذف من نسخة التشغيل بعد الفحص.
- `apps/web/tests/e2e/__snapshots__/`: صور المقارنة المعتمدة لاختبارات Playwright، تظل في Git.
- `docs/quality/`: تقارير المراجعة النصية تظل في Git؛ الصور والفيديوهات والأرشيفات المولّدة متجاهلة، مع استثناء صورة واحدة مطلوبة لفحص إصدار موثّق.
- `.local/` و`.tmp/` و`test-results/` و`playwright-report/` و`blob-report/`: مخرجات تشغيل محلية متجاهلة.
- صور `docs/assets/` الخام المكررة ونسخ Figma المرفوضة تحت `recovery_candidates/` لا تدخل Git أو الديبلوي.

`node scripts/clean-generated-artifacts.mjs` يعرض خطة إزالة الملفات المولّدة من تتبّع Git، و`--apply` يطبقها على فهرس Git فقط ويترك النسخ المحلية. الخطة المفصّلة في `.tmp/generated-artifacts-cleanup.json`. لا يعيد هذا الأمر كتابة تاريخ Git؛ الإصدارات القديمة تظل محفوظة في التاريخ.

الزر العائم يظهر بعد النزول في الصفحة، وحلقته الذهبية تتبع نسبة التمرير. الواتساب فوقه، وفوق شريط التنقل السفلي في صفحة المطور على الموبايل. يحترم تقليل الحركة ويعمل بلوحة المفاتيح.

توقيع CodzHub يستخدم حروف Lemonada اللازمة للكلمة فقط، بملف محلي صغير مع رخصة OFL، وألوان مستمدة من [هوية CodzHub](https://codzhub.com/). حقوق عقارات السادات تظل واضحة، ويظهر توقيع التصميم والتطوير كرابط منفصل.
