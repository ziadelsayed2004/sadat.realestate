# استرجاع الرئيسية والتصنيفات وفريق العمل

نطاق الاسترجاع الذي طلبه المالك: بانرات المنصة، التعداد والإحصاءات ونصوص الرئيسية، أنواع العقارات وتصنيفاتها وصورها، تصنيفات المقالات والمجتمع، وفريق العمل وصوره. إعلان تيمبليت عام باسم المنصة يظهر في سكشن الإعلانات إلى أن ينشر إعلان حقيقي. لا تستعاد إعلانات الشركات القديمة أو حساباتها أو العقارات والمشروعات والمقالات ومنشورات المجتمع.

النسخة السابقة للتنظيف الذي اكتمل بنجاح: `/var/backups/elsadatrealestate/20261026T190039Z`. السكربت يتحقق من بصماتها ويأخذ نسخة جديدة من الحالة الحالية قبل الاسترجاع. يستعيد فقط مجموعات العرض المحددة إلى مجموعات مؤقتة في قاعدة البيانات نفسها، ثم يضيف السجلات الناقصة داخل معاملة. أي سجل موجود بالفعل يظل كما هو، وأي تعارض بين معرفين لنفس المفتاح يوقف التنفيذ قبل كتابة السجلات. تستخرج صور المجموعات المختارة فقط؛ صور العقارات ومستندات المستخدمين لا تستخرج.

يعتمد تقييد الأرشيف على `--nsInclude` مع إعادة تسمية المجموعات المؤقتة وفق [توثيق MongoDB الرسمي](https://www.mongodb.com/docs/database-tools/mongorestore/). يحذف السكربت اسم قاعدة البيانات من URI الخاص بأداة الاسترجاع ويحتفظ بقاعدة المصادقة صراحة، حتى لا يضيف اختيار URI نطاقًا أوسع من المجموعات المسموحة. تم اختبار الأرشيف الفعلي وأداة الاسترجاع بهذه الصيغة.

بعد رفع الإصلاح، ينفذ المسؤول على السيرفر:

```bash
cd /root/sadat-release &&
git pull --ff-only origin main &&
sudo bash deploy/native/recover-disk-space.sh &&
sudo bash deploy/native/manage-production.sh update &&
sudo env KEEP_ADMIN_EMAIL='info@elsadatrealestate.com' \
  bash deploy/native/restore-site-presentation.sh \
  /var/backups/elsadatrealestate/20261026T190039Z
```

التحديث يحافظ على البيانات؛ الاسترجاع يوقف خدمات الموقع مؤقتًا، ثم يعيدها عند النجاح أو الفشل. النجاح ينتهي بـ `PRESENTATION_RESTORE_COMPLETE services=healthy`. قائمة المجموعات المسترجعة وأعداد السجلات الجديدة والموجودة تطبع قبل هذه الرسالة. لا تستخدم أوامر `launch` أو `empty` أو إعادة تثبيت الديمو لهذه العملية.

التحقق المحلي المسجل في `docs/quality/guide-runs/presentation-restore-local-latest.json`: نسخة MongoDB فعلية، أرشيف صور، عزل أسماء المجموعات، سلامة حساب الأدمن، عدم استرجاع المحتوى المحذوف، صور فريق العمل والتصنيفات، قراءة الرئيسية الحقيقية، ومنع التكرار أو الكتابة فوق تعديل جديد.
