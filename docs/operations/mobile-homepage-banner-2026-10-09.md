# ظهور البانر على الموبايل

على الشاشات الأصغر من 768 بكسل، تعرض الصفحة الرئيسية صورة البانر الإداري المنشور فوق العنوان والمحتوى ونموذج البحث. تمت إزالة الاقتصاص والتعتيم من الصورة، وأصبح ارتفاعها يتبع أبعادها الأصلية. يزداد ارتفاع القسم بحسب محتواه، فلا تغطي حقول البحث الصورة ولا يخرج النموذج خارج القسم.

لا يتغير ترتيب البانرات أو توقيت تبديلها. عند تبديل صورة بأبعاد مختلفة، تتبع مساحة العرض أبعاد الصورة الجديدة. يظل عرض الكمبيوتر كما هو، وكذلك مقدمة الصفحة العادية عند عدم وجود بانر إداري ساري.

التحقق: 26 اختبار مكونات، وفحص الأنواع والبناء وlint. تختبر رحلة نشر بانرين عرض الصورة والعنوان والمحتوى وتبديلهم بالعربية والإنجليزية على الكمبيوتر والتابلت والموبايل. على الموبايل تفحص نسبة أبعاد الصورة وعدم تعتيمها وعدم تغطيتها بالمحتوى وبقاء البحث داخل القسم وعدم التمرير الأفقي.

لإظهار الإصلاح في الموقع يجب تحديث السيرفر، ثم إعادة تحميل الصفحة:

```bash
cd /root/sadat-release
git pull --ff-only origin main
bash deploy/native/manage-production.sh update
```
