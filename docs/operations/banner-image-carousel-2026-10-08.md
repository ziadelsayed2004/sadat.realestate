# البانرات بصور متبدّلة

## استخدام المالك

1. من **البانرات** أضف بانرًا أو عدّل البانر الحالي.
2. اختر عدة صور من الجهاز مرة واحدة، أو أضفها على دفعات. الحد 20 صورة، و10 ميجابايت لكل صورة، بصيغ JPG وPNG وWebP.
3. المقاس المقترح **1200 × 400 بكسل**. يجب الالتزام بالمقاسات المعتمدة في إعدادات الإعلانات.
4. حدد مدة كل صورة من **3 إلى 60 ثانية**، ثم احفظ. الصور المحفوظة يمكن ترتيبها بالأسهم أو إزالتها، مع حفظ التعديل.
5. للمسودة اضغط **نشر / جدولة** بعد الحفظ. الصور تتبدّل تلقائيًا بالترتيب في الرئيسية. صورة واحدة تظل ثابتة.

زر عرض الإعلان يحتفظ بنفس رابط الوجهة لكل صور البانر. السابق والتالي والإيقاف المؤقت لا ينقلون الزائر من الصفحة. يتوقف التشغيل أثناء التفاعل، عند إخفاء الصفحة، وعند تفعيل تقليل الحركة في الجهاز.

البانرات السابقة تعمل بصورتها القديمة بدون ترحيل بيانات. إثباتات الدفع تظل ملفات خاصة ولا تدخل ضمن صور الإعلان. النشر المرتبط بطلب عميل ما زال يتطلب جدولة الطلب وإثباتًا معتمدًا أو إعفاء مسجلًا.

## التحقق المحلي

- حفظ عدة صور، إعادة فتح المسودة، ترتيب الصور وحذف صورة من الاختيار.
- إعادة محاولة رفع صورة فاشلة بدون تكرار الصورة التي رُفعت بنجاح، وعدم النشر التلقائي.
- تبديل الصور بالمدة المحددة، الإيقاف والتنقل اليدوي وتقليل الحركة، والحفاظ على اختيار البحث.
- التحقق في MongoDB محلي معزول من الترتيب والمدة، الملكية، تعارض النسخة، عدم حذف صورة مستخدمة، وإخفاء الإعلان عند سحب الدفع أو إلغاء الطلب أو انتهاء الفترة.
- اختبارات البانرات والرئيسية، فحص الأنواع، lint، البناء، وحدود حجم الحزم وOpenAPI وPostman.
- تحديث الدليل داخل المنصة وتصديره إلى `docs/operations/owner-user-guide.ar.md`.

## إظهار التعديل على الموقع

بعد رفع الكود، يُحدّث السيرفر بالطريقة المعتادة:

```bash
cd /root/sadat-release
git pull --ff-only origin main
bash deploy/native/manage-production.sh update
```

لم يتم تغيير بيانات الموقع أو نشر التعديل على السيرفر من بيئة التطوير.
