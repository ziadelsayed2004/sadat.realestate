# Population counter and real-estate tips

Population content is represented by an explicit `available`, `draft`, or `unavailable` state. An available value requires a bounded sourced number, source label/URL, date, and administrative reason; draft or unavailable records never expose a number. No production population value is fabricated.

Real-estate tips are localized, ordered, versioned CMS records. Public projections include only published and active tips; empty content is a valid safe state.
