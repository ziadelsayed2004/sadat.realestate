# Source of Truth

ترتيب الحقيقة عند التعارض:

1. Runtime الفعلي والاختبارات بعد بدء التنفيذ.
2. Product Truth في `01_product/PRD_AR.md` وقواعد الأعمال المعتمدة.
3. Figma المعتمد للـlayout/components/states/prototype.
4. مجلدات Drive المرتبطة بكل Screen ID للمرجع البصري النهائي.
5. Developer Handoff الأصلي الموجود في `90_sources/`.
6. ملفات Agent Pack كخطة تنفيذ، وليست دليلًا على أن الكود منفذ.
7. المحادثات والملاحظات القديمة للاستئناس فقط.

## حدود التحليل الحالي

- تم تحليل نص الهاند أوفر، الجداول، الحالات، الأدوار، المسارات، وقواعد الأعمال.
- لم يُرفق Repository يحتوي MERN Runtime؛ لذلك كل مهام التنفيذ تبدأ Open.
- روابط Figma/Drive تظل مرجعًا خارجيًا. قبل أي مهمة visual يجب فتح Frame الفعلي وتسجيل node/link المستخدم في completion evidence.
- الـZIP القديم استُخدم لفهم شكل Agent Pack والـselector فقط؛ لا تنتقل منه أي حقيقة تخص Market Home إلى هذا المشروع.
