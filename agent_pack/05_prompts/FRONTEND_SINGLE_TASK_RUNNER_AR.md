# Frontend Runner

استخدم الـMaster Runner بعد Backend Gate. في مهام Frontend:

- افتح Frames الفعلية المرتبطة بالـScreen IDs وسجل الرابط في evidence.
- استهلك contracts المنفذة فقط؛ لا mocks إنتاجية ولا endpoints مخترعة.
- طبّق loading/empty/error/retry/success وpermission variants.
- Public/Auth responsive؛ Seeker/Provider/Admin Desktop فقط وفق التسليم.
- ar RTL وen/zh-CN LTR، وراجع visual/a11y/e2e.
